## 🚀 Overview

**Blog Generator AI** is a web-based application designed to help users generate structured blog content from simple prompts. Built with Flask and vanilla JavaScript, it streamlines the writing process for creators, marketers, and developers.

---

## 🛠️ Technologies Used

- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: Python (Flask)  
- **Templating**: Jinja2  
- **Deployment**: GitHub Pages / Heroku / Render *(optional)*
